## Repository Structure

- `index.html` - web slide viewer for the current material
- `slides/` - rendered slide images
- `styles.css` - site styling
- `script.js` - slide navigation
- `*.pdf`, `*.pptx` - downloadable source materials

## Adding Future Seminar Materials

For future materials, add each seminar as its own folder so the repository stays easy to browse:

```text
seminar-materials/
  customer-data-safety-training/
    index.html
    slides/
    source.pdf
    source.pptx
  another-seminar/
    index.html
    slides/
    source.pdf
    source.pptx
```

Then update this README with the new web link and source files.
